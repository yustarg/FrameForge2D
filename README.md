# FrameForge

A small C++ 2D game engine built step by step to learn how engines manage frames, memory, resources, and concurrent work.

## Learning goals

- Understand a frame from input through simulation to drawing.
- Make data ownership and lifetime explicit.
- Build a worker pool and express task dependencies.
- Publish complete simulation snapshots for rendering.
- Load and replace scenes asynchronously.
- Investigate allocations, frame time, and thread waits.

## Planned stack

C++20, CMake, and SDL3 for the window, input, and 2D drawing.

## Course

Follow the [seven-day course](docs/course.zh-CN.md). Implementation progresses with each lesson.
